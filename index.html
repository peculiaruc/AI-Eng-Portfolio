Project write-up

Bootcamp

Mastering Backend, AI Engineering Bootcamp. One summary per topic I studied.

  1. Introduction to AI Engineering. Ship a product around a model, with a backend and a way to measure whether it helps.
  2. Prompt and context engineering. Instructions, examples, and retrieved text so the model stays on task.
  3. Project architecture and setup. Folders, environment files, and a layout a teammate can run.
  4. Database layer and migrations. Tables and migrations instead of editing the live database by hand.
  5. Authentication and authorization. Who you are, what you may do, and protected routes.
  6. API design and validation. Clear routes and schemas so bad input fails at the door.
  7. Error handling and testing. Predictable errors, and tests on auth, validation, and the happy path.
  8. Role-based access control. Roles, permissions, and hiding records the caller should not see.
  9. Multi-entity business logic. Users, documents, and conversations with ownership rules.
  10. Background jobs and queues. Work such as ingesting a file that should not block a request.
  11. External API integration. Timeouts, keys, and failing gracefully when another service is down.
  12. Caching strategies. Store expensive results so repeated reads skip the database or the model.
  13. Rate limiting and protection. Caps so one client cannot exhaust the API or the model budget.
  14. Security hardening. Secrets out of Git, HTTPS, headers, and input hygiene.
  15. Observability infrastructure. Logs, health checks, and traces for what failed and how long it took.
  16. Vector database and embeddings. Turn text into vectors so similar meaning can be found.
  17. Document ingestion pipeline. Upload, split, embed, and store a file for later questions.
  18. RAG implementation. Retrieve the closest chunks and answer from that context.
  19. AI agents. A loop that plans a step, calls a tool, then continues or stops.
